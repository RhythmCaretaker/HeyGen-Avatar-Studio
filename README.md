## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Templates:** Import the avatar and video generation templates from `/templates`.
   - **Scripts:** Run the automation scripts from `/scripts` for Video Agent and translation workflows.
   - **Presets:** Apply the Digital Twin, Avatar IV, and voice cloning presets from `/presets`.
4. Launch HeyGen and follow the documentation to apply your configurations.
